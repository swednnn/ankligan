# Ankligan 🦆

Ett svenskt 3D-spel i webbläsaren. Du är en anka som stjäl picknickmat och undviker en arg parkvakt.

## Starta spelet

1. Ladda ner repot med **Code → Download ZIP** och packa upp det.
2. Öppna **ankligan.html** i Chrome eller Edge.
3. Klicka på **Bli ankan**.

Ingen installation, server eller externa bibliotek behövs. Webbläsaren behöver stöd för WebGL.

## Kontroller

| Kontroll | Gör så här |
| --- | --- |
| Mus | Titta runt och vänd ankan |
| W / pil upp | Gå framåt dit du tittar |
| S / pil ner | Gå bakåt |
| A/D / pil vänster/höger | Gå i sidled |
| Två riktningar samtidigt | Gå diagonalt |
| Mellanslag | Kvacka och locka vakten |
| Esc / P | Pausa och släpp musen |

Om webbläsaren inte kan fånga musen finns dragstyrning: håll musknappen nere i spelbilden och dra för att titta.

## Uppdrag

Samla åtta matbitar och återvänd till den blå dammen innan tiden tar slut. Göm dig i buskar för att undvika vakten. Vakten får ett argt ansikte när han jagar dig.

Varje ny omgång slumpar en av fem kartor, utan direkt upprepning:

- Blomsterparken
- Palmstranden
- Snödalen
- Höstlunden
- Takträdgården

Tryck **Esc → Ny slumpad karta** för att börja en ny omgång.

## Lär dig ändra koden

Allt finns i [ankligan.html](./ankligan.html), med svenska förklaringar.

- **Avsnitt 1:** hastigheter, speltid och muskänslighet.
- **Avsnitt 3:** de fem kartornas platser och färger.
- **Avsnitt 6 B:** musstyrningen.
- **Avsnitt 8:** ankans rörelse.
- **Avsnitt 11:** 3D-figurer och miljöer byggda av klossar.

Spara filen och ladda om webbläsaren efter en ändring.
